    Add or change a provider

    Keys are kept only in the Windows credential store, one per provider. Each save is read back before it says "saved". A key is never written to a file, a log or the audit log, and this page only ever shows its last 4 characters.

    When the cloud fails

    Off (default): a failed cloud call stops the request and the chat says why (key, credits, rate limit, network, time-out); the local model is never loaded for it. On: the local model answers instead (it loads first, which can take a minute) and the chat says so. In Cloud mode the local model is unloaded and never started ahead of time.

    Budget

    0 = unlimited while the active provider's prices are 0 (free credits). With prices set, the budget is counted from them and 0 means no cloud spending.
